# GENML

Create and validate your own XML and transform it into a HTML.

## Installation

Obtain the source code to your device:

```bash
git clone https://github.com/UO277938/GENML.git
```

### Frontend
Open the folder /frontend with Visual Studio Code or any similar editor.

### Backend
Open the folder /backend with IntelliJ IDEA or any similar editor (only tested in IntelliJ).

## Usage

### Frontend
To run it you need React/npm.
In the folder /frontend, use this command to start this part of the application locally:
```bash
npm run dev
```
### Backend
To run it you need Java JDK, Maven and SpringBoot.
In the folder /backend, use the editor launch option or F5.
