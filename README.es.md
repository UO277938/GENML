# GENML

Crea y valida tu propio XML y transformalo en un HTML.

## Installation

Obten el código fuente a tu dispositivo:

```bash
git clone https://github.com/UO277938/GENML.git
```

### Frontend
Abre la carpeta /frontend con Visual Studio Code o cualquier editor similar.

### Backend
Abre la carpeta /backend con IntelliJ IDEA o cualquier editor similar (solo se ha probado con IntelliJ).

## Usage

### Frontend
Para ejecutarlo necesitas React/npm.
En la carpeta /frontend, usa este comando para iniciar esta parte de la aplicación de forma local:
```bash
npm run dev
```
### Backend
Para ejecutarlo necesitas Java JDK, Maven y SpringBoot.
En la carpeta /backend, usa la ejecución del editor o F5.
